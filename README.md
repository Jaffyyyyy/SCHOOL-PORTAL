# SCHOOL-PORTAL — Dashboard (infographic-dashboard)

This branch upgrades the repository to a role-based school portal with admin controls, teacher uploads, and a backup endpoint.

Quick start (backend):

1. cd server
2. cp .env.example .env
3. npm install
4. npm start

A seeded admin user will be created automatically using values in the .env or defaults. Change ADMIN_PASSWORD in .env before first run for security.

Front-end: The branch will be extended with a polished infographic UI and login pages. For now, API endpoints are available for integration.
